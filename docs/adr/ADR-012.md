# ADR-012: 额外 USART/UART 驱动

## 状态

Done

## Phase

P1

## 目标

> GitHub Issue: #17
> 验证级别: MEASURED

扩展 NuttX serial 驱动支持 STM32N6 的全部 USART/UART 实例，
支持多串口同时工作。

## 上下文

ADR-002 仅实现了 USART1（PE5/PE6）作为控制台。
STM32N647X0 有多个 USART/UART 实例：
- USART1-3（同步/异步）
- UART4-8（异步）

DS14791 Section 28: USART。
多串口用于调试日志、GPS 模块、蓝牙通信等场景。

## 决策

EdgeSight 项目仅需 USART1 作为 NSH 控制台，其余串口按需可选：

- **USART1** (PE5/PE6): 主控制台，必需。已在 ADR-002 中实现。
- **USART2** (可选): 预留用于调试日志输出或外接模块，暂不实现。
- **USART3 / UART4-8**: EdgeSight 不使用，不实现。

驱动架构保持多端口扩展能力（g_uartN_port 数组），但仅编译使能 USART1。
如后续需要第二串口，通过 Kconfig `CONFIG_STM32N6_USART2=y` 开启即可。

## 设计

### 模块架构

```
扩展 serial 驱动 (stm32n6_serial.c)
├── g_uart1_port — USART1 (已有, 控制台)
├── g_uart2_port — USART2 (新增)
├── g_uart3_port — USART3 (新增)
├── g_uart4_port — UART4  (新增)
└── ...

每个端口包含:
├── uart_ops_s 回调结构体
├── TX/RX 环形缓冲区 (64B)
├── IRQ 编号
└── 时钟/引脚配置
```

### NuttX 框架对接

```
arm_serialinit():
  uart_register("/dev/console", &g_uart1_port)  ← 已有
  uart_register("/dev/ttyS1", &g_uart2_port)    ← 新增
  uart_register("/dev/ttyS2", &g_uart3_port)    ← 新增
  ...

应用层使用:
  fd = open("/dev/ttyS1", O_RDWR)
  read(fd, buf, len)   ← UART2 接收
  write(fd, buf, len)  ← UART2 发送
```

## 理由

EdgeSight 的外设通信走 Ethernet (MQTT) 和 CSI-2 (摄像头)，不依赖额外串口。
仅保留 USART1 控制台可减少代码体积和中断开销。
多串口框架保持可扩展性，后续需求变更时成本低。
