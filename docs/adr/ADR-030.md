## 目标

> GitHub Issue: #35
> 验证级别: MEASURED

实现 STM32N6 DTS（Digital Temperature Sensor）驱动，
用于芯片内部温度监测和热保护。

## 上下文

STM32N647X0 内置数字温度传感器（DTS），特性：
- 测量芯片结温
- 数字输出（无需 ADC）
- 可配置采样率
- 过温/低温中断

DS14791 Section 24: Digital temperature sensor (DTS)。
DTS 用于芯片热管理、NPU 热保护、系统健康监测。

## 决策

使用 DTS 进行 CPU 芯片结温监测：

- **采样模式**: 连续测量（Continuous），read() 时轮询 SMPL_DONE 取样
- **NuttX 接口**: 注册为 `/dev/temp0` 字符设备，read() 返回一个 `b16_t`
  (Q16.16) 摄氏度采样；应用层周期性 read() 获取温度值
- **初始化位置**: `board_late_initialize()` → `board_bringup.c`
- **温度换算**: STM32N6 DTS 为 PVT/TSC 传感器，换算使用数据手册给定的
  固定常数（G=60.0, H=200.0, J=−0.1, Cal5=4094, Fclk_ts=4MHz），
  **不依赖 OTP 校准**，化简为 `Temp(°C) = 200·sample/4094 − 40.4`；
  驱动用整型定点实现（内核未开 FPU）：
  `temp_b16 = 13107200·sample/4094 − 2647654`

**本轮不实现**（超出最小可测范围，且真机无外部加热手段验证阈值）：
- 过温/低温阈值中断（THIGH/TLOW）与 TS_INT 回调
- NPU 频率联动的热保护逻辑

保留连续测量 + /dev/temp0 读取这一最小可测闭环，未来需要热保护时再叠加
阈值中断。

## 设计

### 模块架构

```
DTS (数字温度传感器)
├── 测量范围
│   ├── -40°C ~ +125°C
│   └── 分辨率 0.1°C (典型)
│
├── 工作模式
│   ├── 单次测量 (One-shot)
│   ├── 连续测量 (Continuous)
│   └── 低功耗采样
│
└── 中断/告警
    ├── 高温阈值 (THIGH)
    ├── 低温阈值 (TLOW)
    └── 中断输出 (TS_INT)
```

### NuttX 框架对接

实现为最简字符设备（`register_driver`），read() 返回一个 `b16_t` 采样；
不使用 NuttX sensor 上层框架（避免为单一读值引入额外依赖）：

```
字符设备 /dev/temp0 (mode 0444):
  register_driver("/dev/temp0", &g_dts_fops, ...)

应用层:
  fd = open("/dev/temp0", O_RDONLY)
  read(fd, &temp, sizeof(b16_t))   // temp 为 Q16.16 摄氏度
  → b16toi(temp) 取整数度数
```

### 采样时序（SDIF 间接寄存器）

```
Init : 时钟合成 4MHz (TSCCLKSYNTHR = CLK_SYNTH_EN|HOLD)
     → SDA 写 TIMERR=256 上电延时 → PVT_IER 使能 TS_IRQ
     → 清 TSCSDIFDIS
Cfg  : SDA 写 CFGR = RESOLUTION_12BITS
Start: SDA 写 CR = MODE_CONTINUOUS
Read : 轮询 S0_DONER.SMPL_DONE (带超时)
     → 读 S0_DATAR，拒绝 SAMPLE_TYPE/SAMPLE_FAULT，掩码取 16bit 数据
     → 定点换算为 b16_t
```

## 理由

NPU 满载推理时芯片温度较高，DTS 监测可防止过温损坏并提供用户可见状态。
1Hz 采样率足够反映温度趋势，不会给 CPU 带来额外负担。
DTS 无需 ADC 通道，硬件独立，驱动简单可靠。
