## 上下文

STM32N647X0 内置数字温度传感器（DTS），特性：
- 测量芯片结温
- 数字输出（无需 ADC）
- 可配置采样率
- 过温/低温中断

DS14791 Section 24: Digital temperature sensor (DTS)。
DTS 用于芯片热管理、NPU 热保护、系统健康监测。

## 设计

### 模块架构

```
DTS (数字温度传感器)
├── 测量范围
│   ├── -40°C ~ +125°C
│   └── 分辨率 0.1°C (典型)
│
├── 工作模式
│   ├── 单次测量 (One-shot)
│   ├── 连续测量 (Continuous)
│   └── 低功耗采样
│
└── 中断/告警
    ├── 高温阈值 (THIGH)
    ├── 低温阈值 (TLOW)
    └── 中断输出 (TS_INT)
```

### NuttX 框架对接

```
NuttX 温度传感器框架:
  sensor_register("/dev/temp0", &dts_sensor)

应用层:
  fd = open("/dev/temp0", O_RDONLY)
  read(fd, &sensor_data, sizeof(sensor_data))
  → sensor_data.temperature (单位: 0.01°C)

过温保护:
  dts_set_threshold(thigh: 85°C)
  → 超过阈值触发中断
  → 回调: 降低 NPU 频率 / 系统保护
