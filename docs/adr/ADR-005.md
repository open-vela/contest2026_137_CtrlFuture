# ADR-005: RCC 时钟树完善（HSE, PLL2-4, LSI/LSE）

## 状态

In Progress (NuttX driver implemented, PLL2-4 and LSI/LSE pending)

## Phase

P1

## 目标

> GitHub Issue: #10
> 验证级别: MEASURED

完善 STM32N6 RCC 时钟树配置，支持 HSE 外部晶振、PLL2/PLL3/PLL4 倍频、
LSI/LSE 低速时钟源，为所有外设提供精确时钟。

## 上下文

ADR-002 仅配置了 HSI 64MHz 内部振荡器作为系统时钟。
STM32N6 的外设需要多种时钟频率：
- CPU 最高 800MHz（需 PLL 倍频）
- USB 需要 48MHz 精准时钟
- RTC 需要 32.768kHz LSE
- 看门狗需要 LSI ~32kHz

DS14791 Section 7: RCC 时钟树包含 4 个 PLL（PLL1-4），
每个 PLL 有独立的 VCO、分频/倍频因子。

## 决策

采用三路 PLL 配置方案，基于 HSE 64MHz 晶振输入：

1. **PLL1（CPU 时钟）**: M=2, N=25, P=1 → 800MHz CPU 核心时钟
   - 默认保守运行于 200MHz（AHB DIV4）
   - 通过 `CONFIG_EDGESIGHT_CLOCK_800MHZ` 宏启用全速 800MHz
   - 需要 SMPS overdrive 模式 + Voltage Scale 0 才能稳定运行于 800MHz

2. **PLL2（NPU 时钟）**: M=8, N=125, P=1 → 1GHz NPU 时钟
   - Neural-ART NPU 需要最高频率以达到 600 Gops 算力

3. **PLL4（外设时钟）**: M=32, N=40, P=1 → 80MHz 外设总线时钟
   - 为 USART、SPI、I2C 等外设提供统一时钟基准

电源配置要求：
- SMPS 切换至 overdrive 模式
- PWR voltage scaling 设置为 Scale 0（最高性能档位）
- 上电后先等待电压稳定再切换 PLL

实现文件：
- `board/contest_board/include/board.h` — PLL 参数宏定义与时钟树配置
- `board/contest_board/src/stm32n6_clockconfig.c` — 时钟初始化实现

## 设计

### 模块架构

RCC 时钟树分为 4 层：

```
时钟源层
├── HSI 16MHz (内部高速)     ← ADR-002 已使用
├── HSE 32MHz (外部晶振)     ← 本 ADR 新增
├── CSI 4MHz (内部低功耗)    ← 低功耗模式备用
├── LSI ~32kHz (内部低速)    ← IWDG 看门狗
└── LSE 32.768kHz (外部低速) ← RTC 实时时钟

PLL 层
├── PLL1 (系统时钟)          ← CPU/AHB/APB 总线
├── PLL2 (外设时钟)          ← SPI/I2C/USART
├── PLL3 (外设时钟)          ← USB/SAI
└── PLL4 (外设时钟)          ← LTDC/DSI

时钟输出层
├── SYSCLK → CPU (最高 800MHz)
├── AHB1-5 分频 → DMA/GPIO/Ethernet
├── APB1-4 分频 → USART/SPI/I2C/TIM
└── 专用时钟 → USB48M/SAI/ETH_REF
```

### NuttX 框架对接

RCC 驱动在 NuttX 启动链中的位置：

```
__start()
  → stm32n6_clockconfig()     ← ADR-002 最小实现
    → rcc_enablehsi()         ← 已实现
    → rcc_enablegpioe()       ← 已实现
    → rcc_enableusart1()      ← 已实现
    → rcc_enablepll()         ← 本 ADR 扩展
    → rcc_configsysclk()     ← 本 ADR 扩展

NuttX 外设驱动通过以下 API 获取时钟频率：
  → up_get_sysclk()          ← SYSCLK 频率
  → up_get_periphclk(bus)    ← 外设总线时钟
```

### 数据流

```
HSE 32MHz (外部晶振)
  │
  └─→ PLL1 (VCO: 100-800MHz)
       ├─ DIVM1 分频 → PREDIV
       ├─ DIVN1 倍频 → VCO
       └─ DIVP1/DIVQ1/DIVR1 分频
            │
            ├─ SYSCLK (最高 800MHz)
            │    ├─ AHB prescaler → HCLK (CPU)
            │    └─ APB1-4 prescaler → 外设时钟
            │
            ├─ PLL2 → SPI/I2C/USART 时钟
            ├─ PLL3 → USB 48MHz
            └─ PLL4 → LTDC 像素时钟
```

## 理由

1. **保守默认 + 可选全速**: 200MHz 默认避免开发阶段因电源不稳定导致的 hard fault，同时通过编译宏可随时切换至 800MHz 全速。
2. **PLL 分配策略**: 将 CPU、NPU、外设分配到不同 PLL，避免频率耦合，便于独立调整。
3. **电源先行**: 必须先配置 SMPS overdrive 和 voltage scale 0，再切换高频 PLL，否则 CPU 在欠压状态下运行不稳定。
4. **NPU 独立 PLL**: NPU 需要 1GHz 时钟才能达到标称 600 Gops，使用 PLL2 独立供给避免影响 CPU 时钟。
