# ADR-023: USB OTG HS

## 状态

Proposed

## Phase

P3

## 目标

> GitHub Issue: #28
> 验证级别: MEASURED

实现 STM32N6 USB OTG HS 驱动，支持 USB 设备/主机模式，
用于 USB CDC（虚拟串口）、MSC（大容量存储）等。

## 上下文

STM32N647X0 有 USB OTG HS 控制器，支持：
- USB 2.0 High-Speed (480Mbps)
- OTG（On-The-Go）设备/主机切换
- 多种设备类（CDC/MSC/HID/Audio）

DS14791 Section 38: USB OTG HS。
电源管理依赖 ADR-009（PWR）。

## 设计

### 模块架构

```
USB OTG HS 控制器
├── 设备模式
│   ├── CDC ACM (虚拟串口)
│   ├── MSC (大容量存储)
│   ├── HID (人机接口)
│   └── 复合设备
│
├── 主机模式
│   ├── USB Flash 驱动器
│   ├── USB 键盘/鼠标
│   └── USB Hub
│
└── OTG 模式
    └── 自动设备/主机切换
```

### NuttX 框架对接

```
NuttX USB 设备栈:
  usbdev_register(&usbdev_driver)
    → /dev/ttyACM0 (CDC)

NuttX USB 主机栈:
  usbhost_register(&usbhost_driver)
    → 枚举连接的 USB 设备
```
