# ADR-022: Ethernet GMAC (1G)

## 状态

Done

## Phase

P3

## 目标

> GitHub Issue: #27
> 验证级别: MEASURED

实现 STM32N6 GMAC（千兆以太网 MAC）驱动，
支持 10/100/1000Mbps 网络通信。

## 上下文

STM32N647X0 内置 GMAC 控制器，支持：
- 10/100/1000Mbps 速率
- MII/RMII/RGMII 接口
- IEEE 1588 PTP 时间同步

DS14791 Section 37: GMAC。
以太网用于网络通信、远程调试、OTA 升级。

## 决策

EdgeSight Ethernet 方案：

1. **接口**: RMII 模式，连接 LAN8742 PHY（STM32N6570-DK 板载）
2. **速率**: 100Mbps（RMII 最高支持 100M，够用于 MQTT + RTSP）
3. **网络栈**: lwIP（NuttX 原生集成，CONFIG_NET_LWIP）
4. **IP 配置**: DHCP 优先，fallback 到静态 IP (192.168.1.100)
5. **应用层协议**:
   - MQTT: 告警推送，QoS 1，重连机制
   - RTSP: 可选实时预览流（H.264 over RTP）
6. **DMA**: GMAC 内置 DMA 引擎，TX/RX descriptor ring

NuttX 驱动移植参考：
- `arch/arm/src/stm32h7/stm32_ethernet.c`（H7 GMAC 寄存器布局相似）
- ST VENC_RTSP_Server 例程的 PHY 初始化序列

网络 HAL 封装：`app/edgesight/network_hal.c`

## 设计

### 模块架构

```
GMAC 控制器
├── MAC 层
│   ├── 发送/接收 FIFO
│   ├── DMA 引擎
│   └── 帧过滤
│
├── PHY 接口
│   ├── MII (标准)
│   ├── RMII (精简)
│   └── RGMII (千兆)
│
└── NuttX 网络栈
    └── netdev_register() → eth0
```

### NuttX 框架对接

```
NuttX 网络栈:
  netdev_register(&gmac_dev)
    → eth0 接口
    → DHCP / 静态 IP

应用层:
  socket(AF_INET, SOCK_STREAM, 0)
  connect(fd, &addr, sizeof(addr))
  send(fd, buf, len, 0)
```

### 数据流

```
发送:
  应用 → socket send()
    → TCP/IP 协议栈 → GMAC TX FIFO
    → DMA → GMAC TX DMA → PHY → 网络

接收:
  网络 → PHY → GMAC RX DMA
    → GMAC RX FIFO → DMA → 内存
    → GMAC 中断 → netdev_input()
    → TCP/IP 协议栈 → socket recv() → 应用
```
