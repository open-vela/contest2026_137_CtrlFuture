# ADR-037: 加密加速器（SAES, HASH, RNG）

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #42
> 验证级别: BUILD

实现 STM32N6 加密加速器驱动，
包括 SAES（AES）、HASH（SHA）、RNG（随机数生成器）。

## 上下文

STM32N647X0 有硬件加密引擎，特性：
- SAES: AES-128/192/256，ECB/CBC/CTR/GCM
- HASH: SHA-1/224/256/384/512，HMAC
- RNG: 真随机数发生器（TRNG）
- 硬件加速，比软件实现快 10-100 倍

DS14791 Section 15: SAES, Section 16: HASH, Section 17: RNG。
加密加速器用于安全通信、固件签名、密钥管理。

## 设计

### 模块架构

```
加密加速器
├── SAES (AES 加密)
│   ├── AES-128/192/256
│   ├── 模式: ECB/CBC/CTR/GCM/CCM
│   ├── DMA 传输支持
│   └── 密钥寄存器 / OTP 密钥
│
├── HASH (哈希)
│   ├── SHA-1, SHA-224, SHA-256
│   ├── SHA-384, SHA-512
│   ├── HMAC
│   └── DMA 传输支持
│
└── RNG (随机数)
    ├── 真随机数 (TRNG)
    ├── 噪声源: 模拟振荡器
    └── 健康检测 (自检)
```

### NuttX 框架对接

```
NuttX crypto 框架:
  crypto_register("aes", &saes_ops)
  crypto_register("sha256", &hash_ops)
  /dev/hwrng (RNG 设备)

应用层 (加密):
  fd = open("/dev/crypto", O_RDWR)
  crypt_op op = { .op = COP_ENCRYPT, .cipher = "aes-cbc" };
  ioctl(fd, CIOCCRYPT, &op)

应用层 (随机数):
  fd = open("/dev/hwrng", O_RDONLY)
  read(fd, buf, 32)
  → 32 字节真随机数
```

### 数据流

```
AES 加密:
  明文 → SRAM
    → SAES DMA 读取 → AES 核心
    → 密文 → DMA → SRAM

SHA-256 计算:
  数据 → SRAM
    → HASH DMA 读取 → SHA 核心
    → 哈希值 (32B) → 寄存器

TLS 握手:
  RNG → 随机数生成
    → RSA/ECDH 密钥交换
    → AES-GCM 加密通道
