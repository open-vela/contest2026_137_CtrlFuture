## 目标

> 验证级别: MEASURED

实现 STM32N6 I2C 驱动，支持 I2C1-4 全部实例，
支持主/从模式、DMA 传输、100K/400K/1MHz 速率。

## 上下文

STM32N647X0 有 4 个 I2C 实例（I2C1-4），
支持标准模式（100K）、快速模式（400K）、
快速模式+（1MHz）。DS14791 Section 31: I2C。

I2C 用于连接传感器、EEPROM、PMIC 等低速外设。

## 设计

### 模块架构

```
NuttX I2C 框架
├── i2c_master_s — I2C 主设备接口
│   ├── i2c_transfer()    ← 传输事务
│   ├── i2c_setfrequency() ← 速率设置
│   └── i2c_reset()       ← 总线复位
│
└── STM32N6 I2C 驱动
    ├── 主模式 (默认)
    ├── 从模式 (可选)
    └── DMA 模式 (可选)
```

### NuttX 框架对接

```
I2C 设备注册:
  i2c_register(i2c_dev, bus_num)
    → /dev/i2cN

传感器驱动使用:
  struct i2c_master_s *i2c = stm32n6_i2cbus_initialize(1)
  i2c_transfer(i2c, msgs, nmsgs)
```

### 数据流

```
I2C 写操作:
  应用 → i2c_transfer()
    → START → 设备地址(W) → 寄存器地址 → 数据 → STOP

I2C 读操作:
  应用 → i2c_transfer()
    → START → 设备地址(W) → 寄存器地址
    → RESTART → 设备地址(R) → 数据 → STOP
```
