# ADR-014: I2C 驱动（I2C1-4）

对板载 AP3216C(@0x1E) 完成写/回读握手，证明 I2C4 总线双向真实传输）

## Phase

P1

## 目标

> GitHub Issue: #19
> 验证级别: MEASURED

实现 STM32N6 I2C 驱动，支持 I2C1-4 全部实例，
支持主/从模式、DMA 传输、100K/400K/1MHz 速率。

## 上下文

STM32N647X0 有 4 个 I2C 实例（I2C1-4），
支持标准模式（100K）、快速模式（400K）、
快速模式+（1MHz）。DS14791 Section 31: I2C。

I2C 用于连接传感器、EEPROM、PMIC 等低速外设。

## 决策

EdgeSight I2C 使用方案：

1. **I2C4**: 连接摄像头模组 (IMX335) 控制通道，400KHz 快速模式
2. **I2C1**: 连接温湿度传感器（可选），100KHz 标准模式
3. **驱动架构**: 参考 STM32H7 I2C 驱动移植，使用中断模式（非 DMA）
4. **NuttX 框架**: 注册为 /dev/i2c4，camera HAL 通过 i2c_transfer() 访问

实现优先级：I2C4（摄像头配置必须）> I2C1（传感器可选）。
I2C2/I2C3 本项目不使用，暂不实现。

## 实现现状（2026-07-31 达成 MEASURED）

`arch/arm/stm32n6/src/stm32n6_i2c.c` 是完整的主模式 transfer 驱动
（`stm32n6_i2c_transfer` + `stm32n6_i2cbus_initialize` + CR1/CR2/TIMINGR
寄存器编程，经 `i2c_putreg/getreg` 访问器），已列入 `Make.defs` /
`CMakeLists.txt` 编译并接入 `nsh-test` defconfig。

真机达成 MEASURED 时补齐了以下此前的缺口：

- **时钟使能**：I2C4 时钟位在 `APB4ENR1`（bit 7），不同于 I2C1-3 的
  `APB1ENR1`；初始化时经 `RCC_CCIPR4.I2C4SEL` 选 HSI 作内核时钟。
- **引脚 AF 修正**：I2C4 走 **PE13(SCL)/PE14(SDA) AF4，开漏 + 上拉**
  （依据 ALIENTEK STM32N647 板 ST 官方 BSP 权威接法；此前误标 ADR-006
  的 PB6/PB7 AF6，实测总线超时）。
- **初始化顺序**：v2 I2C 的 `TIMINGR` 仅在 `PE=0` 时可写，清 PE 即软
  复位；先清 PE→写 TIMINGR→置 PE。
- **repeated-start 竞态**：非末条消息传完后等 `TC` 再发下一个 START，
  寄存器式读取（写寄存器地址→RESTART→读）时序才正确。

**免跳线真机验证**：板载 AP3216C 环境光/接近/红外传感器挂在 I2C4、
地址 0x1E。自测程序 `ap3216c_test`（`app/ap3216c_test_app/`）软复位后
向系统配置寄存器 0x00 写 0x03（使能 ALS+PS+IR），再以 repeated-start
回读，断言回读值 == 0x03。写入被 ACK + 回读匹配，直接证明 I2C4 总线
双向真实传输，无需外部跳线或仪器（仿 ADR-030 DTS 的板载器件模式）。

> 注（勘误）：此前文档与 `app/edgesight/env_sensor.c` 注释提到"板载
> SHT30(@0x44)"，实为 EdgeSight 规划性描述，非本开发板真实硬件。整个
> ST 软件包内无 SHT30；I2C4 上真实存在的从机是 AP3216C(@0x1E)。

## 设计

### 模块架构

```
NuttX I2C 框架
├── i2c_master_s — I2C 主设备接口
│   ├── i2c_transfer()    ← 传输事务
│   ├── i2c_setfrequency() ← 速率设置
│   └── i2c_reset()       ← 总线复位
│
└── STM32N6 I2C 驱动
    ├── 主模式 (默认)
    ├── 从模式 (可选)
    └── DMA 模式 (可选)
```

### NuttX 框架对接

```
I2C 设备注册:
  i2c_register(i2c_dev, bus_num)
    → /dev/i2cN

传感器驱动使用:
  struct i2c_master_s *i2c = stm32n6_i2cbus_initialize(1)
  i2c_transfer(i2c, msgs, nmsgs)
```

### 数据流

```
I2C 写操作:
  应用 → i2c_transfer()
    → START → 设备地址(W) → 寄存器地址 → 数据 → STOP

I2C 读操作:
  应用 → i2c_transfer()
    → START → 设备地址(W) → 寄存器地址
    → RESTART → 设备地址(R) → 数据 → STOP
```

## 真机验证（MEASURED）

> 验证平台: 真实 STM32N647 开发板（远程 SSH+GDB+串口，ALIENTEK N647）
> 验证日期: 2026-07-31

- **自测程序**: `ap3216c_test`（`app/ap3216c_test_app/`），NSH builtin
- **从设备**: 板载 AP3216C(@0x1E)，I2C4 PE13/PE14 AF4，400 kHz
- **方法**: 软复位 → 写 0x03 到系统配置寄存器 0x00（使能 ALS+PS+IR）→
  以 repeated-start 回读该寄存器，断言回读 == 0x03；另打印一帧 IR/ALS/PS
- **结果**: `AP3216C PASS (mode=0x03 ir=0 als=0 ps=0)`。写入被 ACK + 回读
  匹配，证明 I2C4 总线双向真实传输（免跳线免仪器）。ir/als/ps=0 属正常
  ——软复位后刚使能、尚未完成一个转换周期，核心证据是写/回读握手。
- **回归**: 纳入 `scripts/hw-verify-drivertest.sh`，与其余 17 项 drivertest
  一次启动全绿（dma2d 为设计内 XFAIL）。
