# ADR-029: ADC 驱动

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #34
> 验证级别: MEASURED

实现 STM32N6 ADC 驱动，支持多通道模拟信号采集，
用于传感器读取、电压检测、电池电量监测等。

## 上下文

STM32N647X0 有 ADC1/ADC2，特性：
- 12-bit SAR ADC，最高 16.5Msps
- 多路复用输入通道
- 支持 DMA 传输
- 注入通道（高优先级）+ 规则通道
- 模拟看门狗（阈值检测）

DS14791 Section 23: ADC。
ADC 是连接模拟世界和数字世界的桥梁。

## 设计

### 模块架构

```
ADC1/ADC2
├── 转换模式
│   ├── 单次转换 (Single)
│   ├── 连续转换 (Continuous)
│   ├── 扫描模式 (Scan, 多通道)
│   └── 注入模式 (Injected, 高优先级)
│
├── 通道配置
│   ├── 规则通道 (Regular, CH0-CH19)
│   ├── 注入通道 (Injected)
│   ├── 采样时间可编程
│   └── 模拟看门狗 (阈值比较)
│
└── 触发源
    ├── 软件触发
    ├── 定时器触发 (TIM1/TIM8 TRGO)
    └── 外部中断触发
```

### NuttX 框架对接

```
NuttX ADC 框架:
  adc_register("/dev/adc0", &adc_dev)

应用层:
  fd = open("/dev/adc0", O_RDONLY)
  read(fd, &adc_msg, sizeof(adc_msg))
  → 返回多通道采样值

DMA 模式:
  定时器触发 → ADC 扫描 → DMA 传输
    → 环形缓冲区 → 应用读取
```

### 数据流

```
单通道查询:
  应用 → read()
    → ADC 软件触发
    → SAR 转换 → DR 寄存器
    → 返回 12-bit 值

多通道 DMA:
  TIM 触发 → ADC 扫描 CH0-CHn
    → DMA → 内存环形缓冲区
    → 中断通知 → 应用 read()
