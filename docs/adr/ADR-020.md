## 目标

> GitHub Issue: #25
> 验证级别: MEASURED

实现 STM32N6 SDMMC 驱动，支持 SD 卡和 eMMC 设备，
提供文件系统存储能力。

## 上下文

STM32N647X0 有 2 个 SDMMC 实例（SDMMC1/2），
支持 SD 卡、SDHC、SDXC、eMMC 设备。
DS14791 Section 35: SDMMC。

SD 卡用于大容量数据存储（日志、配置、数据采集）。

## 设计

### 模块架构

```
SDMMC 驱动
├── 协议支持
│   ├── SD 1-bit 模式
│   ├── SD 4-bit 模式
│   └── eMMC 8-bit 模式
│
├── DMA 传输
│   └── GPDMA → 高速数据传输
│
└── NuttX 块设备
    └── /dev/mmcsdN → FAT/LittleFS 文件系统
```

### NuttX 框架对接

```
NuttX 块设备:
  mmcsd_slotinitialize(slot)
    → /dev/mmcsd0
    → mount("/dev/mmcsd0", "/mnt/sd", "fatfs", ...)

热插拔:
  GPIO 中断 → SD 卡检测
    → mmcsd_inserted() / mmcsd_removed()
```
