# ADR-020: SDMMC 驱动

## 状态

Accepted

## Phase

P2

## 目标

> GitHub Issue: #25
> 验证级别: MEASURED

实现 STM32N6 SDMMC 驱动，支持 SD 卡和 eMMC 设备，
提供文件系统存储能力。

## 上下文

STM32N647X0 有 2 个 SDMMC 实例（SDMMC1/2），
支持 SD 卡、SDHC、SDXC、eMMC 设备。
DS14791 Section 35: SDMMC。

SD 卡用于大容量数据存储（日志、配置、数据采集）。

## 决策

EdgeSight SDMMC 方案：

1. **SDMMC1**: 4-bit SD 模式，连接 microSD 卡槽（STM32N6570-DK 板载）
2. **时钟**: IC4 = PLL1/4 = 200MHz，SDMMC 分频后 50MHz（SDR）
3. **DMA**: 使用 GPDMA（ADR-011）进行数据传输，减少 CPU 占用
4. **文件系统**: FAT32 (FatFS)，支持长文件名（CONFIG_FAT_LFN）
5. **挂载点**: `/mnt/sd`，用于事件录像存储（H.264 clips）
6. **热插拔**: 暂不实现，假设 SD 卡开机前已插入

NuttX 注册路径：
```
stm32n6_sdmmc_initialize()
  → mmcsd_slotinitialize(0, sdio)
  → /dev/mmcsd0
  → mount("/dev/mmcsd0", "/mnt/sd", "vfat", ...)
```

参考 STM32H7 SDMMC 驱动 (`stm32_sdmmc.c`) 移植。

## 设计

### 模块架构

```
SDMMC 驱动
├── 协议支持
│   ├── SD 1-bit 模式
│   ├── SD 4-bit 模式
│   └── eMMC 8-bit 模式
│
├── DMA 传输
│   └── GPDMA → 高速数据传输
│
└── NuttX 块设备
    └── /dev/mmcsdN → FAT/LittleFS 文件系统
```

### NuttX 框架对接

```
NuttX 块设备:
  mmcsd_slotinitialize(slot)
    → /dev/mmcsd0
    → mount("/dev/mmcsd0", "/mnt/sd", "fatfs", ...)

热插拔:
  GPIO 中断 → SD 卡检测
    → mmcsd_inserted() / mmcsd_removed()
```
