## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #37
> 验证级别: MEASURED

实现 STM32N6 GPU2D / DMA2D（Chrom-ART）驱动，
用于 2D 图形硬件加速（填充、复制、混合、格式转换）。

## 上下文

STM32N647X0 有 DMA2D（Chrom-ART）加速器，特性：
- 矩形填充（Solid Fill）
- 矩形复制（Copy）
- 像素格式转换（RGB565↔RGB888↔ARGB8888）
- Alpha 混合（全局/逐像素）
- 硬件 CLUT（颜色查找表）

DS14791 Section 11: DMA2D。
DMA2D 卸载 CPU 的 2D 图形操作，提升 GUI 性能。

## 设计

### 模块架构

```
DMA2D (Chrom-ART)
├── 工作模式
│   ├── 寄存器到存储器 (填充)
│   ├── 存储器到存储器 (复制)
│   ├── 存储器到存储器+PFC (格式转换)
│   └── 存储器到存储器+混合 (Alpha 混合)
│
├── 像素格式
│   ├── ARGB8888 (32-bit)
│   ├── RGB888 (24-bit)
│   ├── RGB565 (16-bit)
│   ├── AL88 (16-bit, Alpha+亮度)
│   └── L8 (8-bit, CLUT)
│
└── 前景/背景层
    ├── FG 输入 (前景)
    ├── BG 输入 (背景)
    └── 输出 (混合结果)
```

### NuttX 框架对接

```
DMA2D 作为 LTDC 辅助引擎:
  GPU2D 填充 → 帧缓冲
  GPU2D 混合 → 双层叠加
  GPU2D PFC → 格式适配

LVGL 集成:
  lv_draw_sw → lv_gpu_stm32_dma2d()
    → DMA2D 加速矩形填充/复制/混合
    → CPU 空闲处理复杂路径
```

### 数据流

```
矩形填充:
  CPU → 配置 DMA2D OCOLR/OMAR/OMAR+NLR
    → DMA2D 写入帧缓冲
    → LTDC 显示

Alpha 混合:
  FG 帧缓冲 + BG 帧缓冲
    → DMA2D 混合
    → 输出帧缓冲
    → LTDC 显示
