# ADR-028: 低功耗定时器（LPTIM1-5）

## 状态

Partially Accepted — LPTIM 定时与低功耗 PWM 均已实现并真机 MEASURED：
- 周期定时器：LPTIM1（/dev/timer1，APB1）+ LPTIM3-5（/dev/timer3-5，APB4），
  均 LSI 时钟，drivertest_timer -d /dev/timerN 逐一 PASS。
- 低功耗 PWM：LPTIM2 作为 /dev/pwm0（LPTIM2_CH1 输出，PF1/AF3，LSI 时钟），
  drivertest_pwm PASS（内部标志 MEASURED，见验证标准）。
PWM 与周期模式共用 CR/CFGR 互斥，故 LPTIM2 专做 PWM、不再暴露 /dev/timer2。
Stop 模式唤醒作为独立子项待实现。

## Phase

P4

## 目标

> GitHub Issue: #33
> 验证级别: MEASURED

实现 STM32N6 低功耗定时器（LPTIM1-5）驱动，
支持低功耗模式下的定时和 PWM 输出。

## 上下文

STM32N647X0 有 5 个低功耗定时器 LPTIM1-5，特性：
- 独立时钟源（LSE 32.768kHz 或 LSI）
- 在 Stop 模式下仍可运行
- 16-bit 计数器
- 2 路输出通道

DS14791 Section 34: Low-power timers LPTIM1-5。
LPTIM 用于低功耗唤醒、PWM 调光、超低频定时。

## 决策

实现 LPTIM1-5 全部作为普通周期定时器下半层，对接 NuttX timer 字符设备框架
（/dev/timer1-5），内核时钟均选 LSI（~32kHz）。下半层做成数据驱动：同一套
ops 与寄存器序列，按实例携带各自的时钟门控/保活/CCIPR12 选择字段——LPTIM1
在 APB1（APB1ENR1/APB1LPENR1），LPTIM2-5 在 APB4（APB4ENR1/APB4LPENR1）。
它们与 TIM2（/dev/timer0）共用同一 drivertest_timer 测试二进制
（`-d /dev/timerN`），无需新测试即可真机验证 LSI 时钟域的周期中断。

低功耗 PWM：LPTIM2 改作 PWM 输出下半层，对接 NuttX PWM 字符设备框架
（/dev/pwm0），驱动 LPTIM2_CH1（PF1，AF3），内核时钟同样选 LSI。PWM 模式
与周期模式共用 CR/CFGR 互斥，故同一实例二选一：Kconfig 用
`STM32_LPTIM2_PWM depends on !STM32_LPTIM2` 强制。LPTIM2 的周期路径与其它
实例数据驱动同源、已 MEASURED，改作 PWM 不损失驱动正确性覆盖（周期定时仍有
LPTIM1 的 APB1 + LPTIM3-5 的 APB4 共 4 个实例）。PWM 波形由硬件自主生成，
不需要中断；正确性由 start() 中 ARROK + CMP1OK 两个握手轮询在真机上确认。

不实现（作为独立子项延后）：Stop 模式下保持计数并唤醒 CPU。EdgeSight 作为
AI 视觉哨兵设备持续接通电源运行，不进入 Stop/Standby，此子项当前无使用
场景；如后续产品化需要电池供电或间歇工作模式再评估。

### LPTIM 与通用定时器的编程模型差异

LPTIM 不能照搬 TIM2 的下半层，几处差异已在驱动中处理：

1. **配置寄存器时序**：CFGR 与中断使能寄存器（DIER）只能在 LPTIM 禁用
   （CR.ENABLE=0）时写；ARR 反之只能在使能后写，且每次写须轮询 ISR.ARROK
   握手（带超时，禁止死等）。
2. **周期事件是 ARRM**：周期中断源是自动重载匹配（ISR.ARRM），非通用定时器
   的更新标志（UIF）；连续计数用 CR.CNTSTRT 启动。
3. **计数器异步读**：计数器由 LSI 驱动，与 APB 读总线异步，单次读可能撞上
   进位中间态，须连读至两次一致（相干读）。
4. **LSI 供电**：驱动自包含使能 LSI（RCC_CR.LSION + 轮询 LSIRDY）并把
   LPTIM1 内核时钟 mux（CCIPR12.LPTIM1SEL）选到 LSI。

预防性套用 TIM2 的教训：置位 `RCC_APB1LPENR1.LPTIM1LPEN`（位9），使 CPU
Sleep(WFI) 期间时钟不门控，故任务 sleep 态计数/中断不失效（真机一次通过，
无 TIM2 曾踩的 sleep 冻结潜伏 bug）。

## 设计

### 模块架构

```
LPTIM1-5 (低功耗定时器)
├── 时钟源
│   ├── LSE (32.768kHz)
│   ├── LSI (~32kHz)
│   └── APB (外部时钟)
│
├── 工作模式
│   ├── 单次定时 (One-shot)
│   ├── 连续定时 (Continuous)
│   ├── PWM 输出
│   └── 编码器模式 (LPTIM1/2)
│
└── 低功耗特性
    ├── Stop 模式下保持运行
    └── 唤醒中断 (WUF)
```

### NuttX 框架对接

```
NuttX PWM 框架 (低功耗 PWM, 已实现):
  pwm_register("/dev/pwm0", &g_lptim2_pwm)

应用层 (低功耗 PWM):
  fd = open("/dev/pwm0", O_RDONLY)
  ioctl(fd, PWMIOC_SETCHARACTERISTICS, &cfg)   # 频率 + 占空比
  ioctl(fd, PWMIOC_START)                       # LPTIM2_CH1 输出

NuttX timer 框架 (周期定时, 已实现):
  timer_register("/dev/timerN", &g_lptimN)      # N = 1/3/4/5

应用层 (定时唤醒, Stop 模式子项待实现):
  → CPU 进入 Stop 模式
  → LPTIM 中断唤醒 CPU
```

## 实施步骤

1. [x] 实现 LPTIM 时钟初始化（使能 LSI + 轮询 LSIRDY → CCIPR12 选 LSI
   内核时钟 → 门控 + sleep 保活；LPTIM1 走 APB1ENR1/APB1LPENR1，LPTIM2-5
   走 APB4ENR1/APB4LPENR1，由下半层实例字段数据驱动）
2. [x] 实现周期定时（CFGR 预分频/PRELOAD + DIER ARRMIE，ENABLE 后写 ARR
   轮询 ARROK，CNTSTRT 连续计数，ARRM 匹配中断），所有握手带超时
3. [x] 集成 NuttX timer 框架（/dev/timer1-5，下半层 ops 复用 timer_ops_s）
4. [x] 编译验证（ci-check 双目标 + renode 回归）+ 真机 MEASURED
   （drivertest_timer 逐一验证 /dev/timer1/3/4/5）
5. [x] 实现低功耗 PWM 输出（LPTIM2 → /dev/pwm0，PWM 下半层 ops 复用
   pwm_ops_s；配 ARR 定周期、CCR1 定占空比，CFGR.WAVE=0 选 PWM 波形，
   CCMR1.CC1E 使能 CH1 输出，CNTSTRT 连续启动；ARROK/CMP1OK 握手带超时）
6. [x] 集成 NuttX PWM 框架并真机 MEASURED（drivertest_pwm 对 /dev/pwm0）
7. [ ] Stop 模式定时唤醒（独立子项待实现）

## 验证标准

- [x] `ci-check.sh` 编译通过（BUILD）
- [x] LPTIM 周期中断正确（drivertest_timer -d /dev/timer1/3/4/5 逐一真机
  PASS，MEASURED：hw-verify-drivertest.sh 回归套件 cmocka_driver_lptim/
  lptim3-5 全 PASSED。`max timeout:2048000` 即 16-bit@LSI 32kHz 的 2.048s
  上限，与 TIM2 的 32-bit 4294967295 明显不同，证明命中的确是 LPTIM 节点）
- [x] LPTIM 低功耗 PWM 输出正确（drivertest_pwm 对 /dev/pwm0 真机 PASS，
  内部标志 MEASURED：start() 在 ARROK + CMP1OK 两个更新握手标志置位后才
  返回 OK，这两个标志仅当 LSI 内核时钟真在运行、寄存器写入跨越 LSI 时钟域
  落定时才置位，否则 -ETIMEDOUT 令测试 FAIL。远程无示波器观测 CH1 物理
  引脚，故为 with-caveat：证明比较/波形引擎按设定翻转，不证明信号到引脚）
- [ ] Stop 模式下定时唤醒正确（低功耗子项待实现）

## 理由

以普通周期定时器形态交付 LPTIM1/3/4/5，用最小代价获得 LSI 时钟域外设的
真机验证覆盖（与 TIM2 的 APB 时钟域互补），并复用现成 drivertest_timer
无需新测试。下半层做成数据驱动，一套代码路径同时服务 APB1 的 LPTIM1 与
APB4 的其余实例，避免近乎重复的实例代码。LPTIM2 改作低功耗 PWM 输出，
覆盖 LPTIM 的第二类核心功能，复用现成 drivertest_pwm；因远程无示波器，
验证走内部标志（ARROK/CMP1OK 握手）而非波形观测，诚实标注 with-caveat。
LPTIM 的最后一项差异化能力（Stop 模式保持运行 + 低功耗唤醒）需 CPU 进入
低功耗模式才能体现，而 EdgeSight 全速运行不进入 Stop，故作为独立子项延后，
不谎称 ADR-028 100% 完成。
