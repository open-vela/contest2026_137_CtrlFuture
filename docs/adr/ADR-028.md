# ADR-028: 低功耗定时器（LPTIM1-5）

## 状态

Partially Accepted — LPTIM1-5 全部作为普通周期定时器实现并真机 MEASURED：
LPTIM1（/dev/timer1，APB1）+ LPTIM2-5（/dev/timer2-5，APB4），均 LSI 时钟，
drivertest_timer -d /dev/timerN 逐一 PASS。Stop 模式唤醒与低功耗 PWM 输出
作为独立子项待实现。

## Phase

P4

## 目标

> GitHub Issue: #33
> 验证级别: MEASURED

实现 STM32N6 低功耗定时器（LPTIM1-5）驱动，
支持低功耗模式下的定时和 PWM 输出。

## 上下文

STM32N647X0 有 5 个低功耗定时器 LPTIM1-5，特性：
- 独立时钟源（LSE 32.768kHz 或 LSI）
- 在 Stop 模式下仍可运行
- 16-bit 计数器
- 2 路输出通道

DS14791 Section 34: Low-power timers LPTIM1-5。
LPTIM 用于低功耗唤醒、PWM 调光、超低频定时。

## 决策

实现 LPTIM1-5 全部作为普通周期定时器下半层，对接 NuttX timer 字符设备框架
（/dev/timer1-5），内核时钟均选 LSI（~32kHz）。下半层做成数据驱动：同一套
ops 与寄存器序列，按实例携带各自的时钟门控/保活/CCIPR12 选择字段——LPTIM1
在 APB1（APB1ENR1/APB1LPENR1），LPTIM2-5 在 APB4（APB4ENR1/APB4LPENR1）。
它们与 TIM2（/dev/timer0）共用同一 drivertest_timer 测试二进制
（`-d /dev/timerN`），无需新测试即可真机验证 LSI 时钟域的周期中断。

不实现（作为独立子项延后）：LPTIM 的核心低功耗差异化能力——Stop 模式下
保持计数并唤醒 CPU、低功耗 PWM/单脉冲输出。EdgeSight 作为 AI 视觉哨兵
设备持续接通电源运行，不进入 Stop/Standby，这些子项当前无使用场景；如
后续产品化需要电池供电或间歇工作模式再评估。

### LPTIM 与通用定时器的编程模型差异

LPTIM 不能照搬 TIM2 的下半层，几处差异已在驱动中处理：

1. **配置寄存器时序**：CFGR 与中断使能寄存器（DIER）只能在 LPTIM 禁用
   （CR.ENABLE=0）时写；ARR 反之只能在使能后写，且每次写须轮询 ISR.ARROK
   握手（带超时，禁止死等）。
2. **周期事件是 ARRM**：周期中断源是自动重载匹配（ISR.ARRM），非通用定时器
   的更新标志（UIF）；连续计数用 CR.CNTSTRT 启动。
3. **计数器异步读**：计数器由 LSI 驱动，与 APB 读总线异步，单次读可能撞上
   进位中间态，须连读至两次一致（相干读）。
4. **LSI 供电**：驱动自包含使能 LSI（RCC_CR.LSION + 轮询 LSIRDY）并把
   LPTIM1 内核时钟 mux（CCIPR12.LPTIM1SEL）选到 LSI。

预防性套用 TIM2 的教训：置位 `RCC_APB1LPENR1.LPTIM1LPEN`（位9），使 CPU
Sleep(WFI) 期间时钟不门控，故任务 sleep 态计数/中断不失效（真机一次通过，
无 TIM2 曾踩的 sleep 冻结潜伏 bug）。

## 设计

### 模块架构

```
LPTIM1-5 (低功耗定时器)
├── 时钟源
│   ├── LSE (32.768kHz)
│   ├── LSI (~32kHz)
│   └── APB (外部时钟)
│
├── 工作模式
│   ├── 单次定时 (One-shot)
│   ├── 连续定时 (Continuous)
│   ├── PWM 输出
│   └── 编码器模式 (LPTIM1/2)
│
└── 低功耗特性
    ├── Stop 模式下保持运行
    └── 唤醒中断 (WUF)
```

### NuttX 框架对接

```
NuttX PWM 框架 (低功耗 PWM):
  pwm_register("/dev/lppwm0", &lptim_dev)

NuttX alarm 框架 (低功耗唤醒):
  alarm_register("/dev/lptim_alarm0", &lptim_alarm)

应用层 (低功耗 PWM):
  fd = open("/dev/lppwm0", O_RDONLY)
  ioctl(fd, PWMIOC_SETCHARACTERISTICS, &cfg)
  → 即使 CPU 进入 Stop 模式，PWM 仍在输出

应用层 (定时唤醒):
  ioctl(fd, TCIOC_SETTIMEOUT, &timeout)
  → CPU 进入 Stop 模式
  → LPTIM 中断唤醒 CPU

- [x] `ci-check.sh` 编译通过（BUILD）
- [x] LPTIM 周期中断正确（drivertest_timer -d /dev/timer1-5 逐一真机 PASS，

## 理由

以普通周期定时器形态交付 LPTIM1-5，用最小代价获得 LSI 时钟域外设的真机
验证覆盖（与 TIM2 的 APB 时钟域互补），并复用现成 drivertest_timer 无需
新测试。下半层做成数据驱动，一套代码路径同时服务 APB1 的 LPTIM1 与 APB4 的
LPTIM2-5，避免五份近乎重复的实例代码。LPTIM 的核心价值（Stop 模式保持运行
+ 低功耗唤醒）需 CPU 进入低功耗模式才能体现，而 EdgeSight 全速运行不进入
Stop，故这些差异化能力作为独立子项延后，不谎称 ADR-028 100% 完成。
