# ADR-028: 低功耗定时器（LPTIM1-5）

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #33
> 验证级别: MEASURED

实现 STM32N6 低功耗定时器（LPTIM1-5）驱动，
支持低功耗模式下的定时和 PWM 输出。

## 上下文

STM32N647X0 有 5 个低功耗定时器 LPTIM1-5，特性：
- 独立时钟源（LSE 32.768kHz 或 LSI）
- 在 Stop 模式下仍可运行
- 16-bit 计数器
- 2 路输出通道

DS14791 Section 34: Low-power timers LPTIM1-5。
LPTIM 用于低功耗唤醒、PWM 调光、超低频定时。

## 设计

### 模块架构

```
LPTIM1-5 (低功耗定时器)
├── 时钟源
│   ├── LSE (32.768kHz)
│   ├── LSI (~32kHz)
│   └── APB (外部时钟)
│
├── 工作模式
│   ├── 单次定时 (One-shot)
│   ├── 连续定时 (Continuous)
│   ├── PWM 输出
│   └── 编码器模式 (LPTIM1/2)
│
└── 低功耗特性
    ├── Stop 模式下保持运行
    └── 唤醒中断 (WUF)
```

### NuttX 框架对接

```
NuttX PWM 框架 (低功耗 PWM):
  pwm_register("/dev/lppwm0", &lptim_dev)

NuttX alarm 框架 (低功耗唤醒):
  alarm_register("/dev/lptim_alarm0", &lptim_alarm)

应用层 (低功耗 PWM):
  fd = open("/dev/lppwm0", O_RDONLY)
  ioctl(fd, PWMIOC_SETCHARACTERISTICS, &cfg)
  → 即使 CPU 进入 Stop 模式，PWM 仍在输出

应用层 (定时唤醒):
  ioctl(fd, TCIOC_SETTIMEOUT, &timeout)
  → CPU 进入 Stop 模式
  → LPTIM 中断唤醒 CPU
