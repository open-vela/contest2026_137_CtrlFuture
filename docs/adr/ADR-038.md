# ADR-038: Secure Boot 安全启动

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #43
> 验证级别: MEASURED

实现 STM32N6 Secure Boot 安全启动链，
确保固件完整性和真实性，防止未授权代码执行。

## 上下文

STM32N6 支持硬件安全启动，特性：
- Boot ROM 验证固件签名（ECDSA/RSA）
- OTP（一次性可编程）存储根公钥哈希
- 安全生命周期管理（Open → Closed → Locked）
- 调试端口控制（JTAG/SWD 锁定）
- 依赖加密加速器（ADR-037）

DS14791 Section 5: Boot and security。
Secure Boot 是产品化的安全基础。

## 设计

### 模块架构

```
Secure Boot 链
├── Boot ROM
│   ├── 读取 OTP 根公钥哈希
│   ├── 验证 Bootloader 签名 (ECDSA-P256)
│   └── 验证通过 → 跳转 Bootloader
│
├── Bootloader (第二阶段)
│   ├── 验证 App 固件签名
│   ├── 版本检查 (防回滚)
│   └── 验证通过 → 跳转 App
│
├── OTP 配置
│   ├── 根公钥哈希 (SHA-256, 32B)
│   ├── 安全生命周期状态
│   ├── 调试端口配置
│   └── 防回滚计数器
│
└── 密钥管理
    ├── 开发密钥 (可恢复)
    ├── 生产密钥 (不可恢复)
    └── 密钥轮换方案
```

### 启动流程

```
安全启动:
  上电 → Boot ROM
    → 读 OTP 根公钥哈希
    → 读 Bootloader 镜像 (Flash)
    → ECDSA 验证签名
    → 验证通过 → 跳转 Bootloader
    → Bootloader 验证 App
    → App 执行

非安全启动 (开发模式):
  上电 → Boot ROM
    → OTP 未烧录 → 跳过验证
    → 直接加载 App
```

### 固件签名流程

```
编译时:
  arm-none-eabi-objcopy → .bin
    → openssl dgst -sha256 -sign priv.pem → .sig
    → 合并: .bin + .sig → final.bin

烧录时:
  烧录 final.bin 到 Flash
  烧录 pub_key_hash 到 OTP (首次)
