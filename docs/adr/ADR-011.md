# ADR-011: GPDMA1 通用 DMA

## 状态

Done

## Phase

P1

## 目标

> GitHub Issue: #16
> 验证级别: MEASURED

实现 GPDMA1（通用 DMA）驱动，支持外设与内存之间的
高速数据传输，减轻 CPU 负担。

## 上下文

STM32N6 有 2 个 GPDMA 实例（GPDMA1/2），
每个有 16 个通道，支持外设到内存、内存到外设、
内存到内存传输。DS14791 Section 12: DMA。

SPI/I2C/UART/ADC 等外设的高性能模式都依赖 DMA。
DMA 与 DCACHE 的一致性需要特殊处理（ADR-007）。

## 决策

EdgeSight GPDMA 通道分配：

| 通道 | 外设 | 方向 | 用途 |
|------|------|------|------|
| CH0 | SDMMC1 TX | M2P | SD 卡写入 |
| CH1 | SDMMC1 RX | P2M | SD 卡读取 |
| CH2 | USART1 TX | M2P | 串口日志（可选） |
| CH3 | USART1 RX | P2M | 串口接收（可选） |
| CH4 | I2C4 TX | M2P | 摄像头配置 |
| CH5 | I2C4 RX | P2M | 摄像头配置 |
| CH14 | M2M | - | 内存拷贝（帧缓冲） |

策略：
1. **DCMIPP 和 VENC 有独立 DMA**: 不占用 GPDMA 通道
2. **GMAC 有内置 DMA**: Ethernet 不占用 GPDMA
3. **链表模式**: SDMMC 使用 linked-list DMA 实现多块传输
4. **Cache 一致性**: DMA 目标缓冲区使用 clean/invalidate（ADR-007）

移植参考：STM32H7 DMA 驱动 + STM32U5 GPDMA 驱动（U5 与 N6 GPDMA 相似）。

## 设计

### 模块架构

```
GPDMA1 (16 通道)
├── 通道分配
│   ├── CH0-3: SPI1-4 DMA
│   ├── CH4-7: USART1-4 DMA
│   ├── CH8-11: I2C1-4 DMA
│   ├── CH12-13: ADC DMA
│   └── CH14-15: 内存到内存
│
├── 传输模式
│   ├── 外设到内存 (P2M) ← 接收
│   ├── 内存到外设 (M2P) ← 发送
│   ├── 内存到内存 (M2M) ← 拷贝
│   └── 链表模式 (Linked-list)
│
└── DMA 请求复用
    └── DMAMUX → 外设请求号映射
```

### NuttX 框架对接

```
NuttX DMA API:
  arm_dma_allocate(ch)       ← 分配通道
  arm_dma_free(ch)           ← 释放通道
  arm_dma_start(ch, cfg)     ← 启动传输
  arm_dma_stop(ch)           ← 停止传输

Cache 一致性操作:
  发送前: up_clean_dcache(buf, len)
  接收后: up_invalidate_dcache(buf, len)
```

### 数据流

```
SPI DMA 发送 (M2P):
  应用 → SPI TX buffer → DCACHE clean → GPDMA CH0
    → SPI TXDR → SPI 总线

SPI DMA 接收 (P2M):
  SPI 总线 → SPI RXDR → GPDMA CH1
    → SPI RX buffer → DCACHE invalidate → 应用
```
