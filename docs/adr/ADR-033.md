## 目标

> 验证级别: MEASURED

实现 STM32N6 DCMIPP（Digital Camera Interface Pixel Pipeline）驱动，
支持摄像头数据采集、ISP 处理和帧缓冲输出。

## 上下文

STM32N647X0 有 DCMIPP 控制器，特性：
- 支持 CSI-2（MIPI）和并行摄像头接口
- 内置 ISP（图像信号处理）：去马赛克、白平衡、色彩校正
- 多管线输出（取景器 + 快照 + 编码器）
- 依赖 HPDMA（ADR-025）进行数据传输

DS14791 Section 41: DCMIPP。
DCMIPP 用于机器视觉、视频会议、AI 图像识别。

## 决策

采用 DCMIPP 双管线架构，封装 ST CMW_CAMERA 中间件，通过 ISP 中间件提供自动曝光/白平衡：

1. **双管线（Dual-Pipe）分工**:
   - PIPE1（显示管线）: 输出 RGB565 格式，硬件缩放至显示分辨率，直接送 LTDC 背景层
   - PIPE2（NN 管线）: 输出 RGB888 格式，硬件裁剪至模型输入尺寸，送 NPU 推理

2. **ISP 中间件集成**:
   - 使用 ST ISP middleware 提供自动曝光（AE）和自动白平衡（AWB）
   - ISP 参数由中间件自动调节，无需手动配置

3. **API 封装层次**:
   - 底层: CMW_CAMERA API（ST 摄像头中间件）
   - HAL 层: camera_hal 提供简化的初始化/启动/停止/获取帧接口
   - 应用通过回调获取帧数据指针，零拷贝

4. **摄像头传感器**: 通过 CSI-2 MIPI 接口连接，具体传感器型号由 CMW 配置决定

5. **帧同步**: DCMIPP 帧完成中断触发回调，应用在回调中获取帧指针进行后续处理

实现文件：
- `app/edgesight/camera_hal.h` — 摄像头 HAL 接口定义
- `app/edgesight/camera_hal.c` — DCMIPP 双管线配置、CMW_CAMERA 封装、ISP 集成

## 设计

### 模块架构

```
DCMIPP 控制器
├── 输入接口
│   ├── CSI-2 (MIPI, 2-lane/4-lane)
│   ├── 并行接口 (8/10/12/14-bit)
│   └── 硬件同步 (VSYNC/HSYNC/PCLK)
│
├── ISP 管线
│   ├── 坏像素校正 (BPC)
│   ├── 黑电平校正 (BLC)
│   ├── 去马赛克 (Demosaic)
│   ├── 白平衡 (AWB)
│   ├── 色彩校正矩阵 (CCM)
│   ├── Gamma 校正
│   └── 降噪 (NR)
│
└── 输出
    ├── Pipe0: 取景器 (低分辨率)
    ├── Pipe1: 快照/编码 (高分辨率)
    └── 像素格式: YUV422/RGB888/NV12
```

### NuttX 框架对接

```
NuttX V4L2 框架:
  video_register("/dev/video0", &dcmipp_dev)

应用层:
  fd = open("/dev/video0", O_RDWR)
  ioctl(fd, VIDIOC_S_FMT, &fmt)
  ioctl(fd, VIDIOC_REQBUFS, &req)
  ioctl(fd, VIDIOC_QBUF, &buf)
  ioctl(fd, VIDIOC_STREAMON, 0)
  read(fd, &buffer, sizeof(buffer))
  → 返回一帧图像数据

AI 推理集成:
  DCMIPP → 帧缓冲 → NPU (ADR-036)
    → 目标检测 / 图像分类
```

### 数据流

```
摄像头数据流:
  CMOS 传感器 → CSI-2 → DCMIPP 输入
    → ISP 处理 → 格式转换
    → HPDMA → SRAM 帧缓冲
    → 应用 read() / mmap()

实时预览:
  DCMIPP Pipe0 → 低分辨率帧
    → LTDC (ADR-031) → LCD 显示

## 理由

1. **双管线并行**: 显示和 NN 推理对分辨率、格式要求不同，硬件双管线可同时输出两种格式，无需 CPU 做格式转换或缩放。
2. **封装 CMW_CAMERA**: ST 提供了完整的摄像头中间件（传感器驱动 + ISP + DCMIPP 配置），直接复用比从寄存器层开始实现节省大量工作。
3. **ISP 自动化**: AE/AWB 对图像质量至关重要，手动调参在不同光照条件下不可靠，ISP 中间件的自动算法足够应付竞赛场景。
4. **零拷贝设计**: 帧数据直接在 SRAM 缓冲区中就地使用，避免大块数据搬运造成的带宽瓶颈。
