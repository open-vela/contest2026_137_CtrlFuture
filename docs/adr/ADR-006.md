# ADR-006: GPIO 完善（165 引脚 AF 映射）

## 状态

Proposed

## Phase

P1

## 目标

> GitHub Issue: #11
> 验证级别: BUILD

完善 STM32N6 全部 165 个 GPIO 引脚的复用功能（AF）映射表，
为所有外设驱动提供统一的引脚配置接口。

## 上下文

ADR-002 仅实现了 PE5/PE6 两个引脚的 USART1 AF7 配置。
STM32N647X0 有 11 个 GPIO 端口（GPIOA-GPIOJ + GPIOZ），
共 165 个引脚，每个引脚最多支持 16 种复用功能（AF0-AF15）。

DS14791 Table 30 列出了完整的 AF 映射表。
后续每个外设驱动（SPI/I2C/UART/ETH/LTDC...）都需要
正确配置对应引脚的 AF。

## 设计

### 模块架构

GPIO 驱动分为 3 层：

```
引脚定义层 (board_pinmap.h)
├── GPIO_USART1_TX  = GPIO_PORT_E | GPIO_PIN_5 | GPIO_AF7
├── GPIO_SPI1_SCK   = GPIO_PORT_A | GPIO_PIN_5 | GPIO_AF5
├── GPIO_ETH_TXD0   = GPIO_PORT_B | GPIO_PIN_12 | GPIO_AF11
└── ... (所有板级引脚定义)

GPIO 驱动层 (stm32n6_gpio.c)
├── stm32n6_configgpio(uint32_t pinset)  ← 32 位编码配置
├── stm32n6_gpioread(uint32_t pinset)    ← 读引脚电平
├── stm32n6_gpiowrite(uint32_t pinset)   ← 写引脚电平
└── stm32n6_gpioirq(...)                 ← EXTI 中断（ADR-010）

硬件层
├── GPIOx_MODER   — 模式 (输入/输出/AF/模拟)
├── GPIOx_OTYPER  — 输出类型 (推挽/开漏)
├── GPIOx_OSPEEDR — 输出速度
├── GPIOx_PUPDR   — 上拉/下拉
├── GPIOx_AFRL/H  — 复用功能选择 (AF0-AF15)
└── GPIOx_IDR/ODR — 输入/输出数据
```

### NuttX 框架对接

GPIO 驱动在 NuttX 中的使用方式：

```
外设驱动初始化时:
  stm32n6_configgpio(GPIO_USART1_TX)   ← 配置引脚 AF
  stm32n6_configgpio(GPIO_USART1_RX)

NuttX GPIO 框架 (可选):
  gpio_lower_half_s → 注册 /dev/gpioN
  → 支持 userspace GPIO 控制
```

### 数据流

```
32 位引脚编码:
  [31:28] port   (0=A, 1=B, ..., 10=Z)
  [27:24] pin    (0-15)
  [23:20] mode   (00=input, 01=output, 10=AF, 11=analog)
  [19:16] af     (0-15)
  [15:12] speed  (00=low, 01=medium, 10=high, 11=very_high)
  [11:8]  pupd   (00=none, 01=pull-up, 10=pull-down)
  [7:4]   otype  (0=push-pull, 1=open-drain)

stm32n6_configgpio(pinset):
  → 提取 port/pin/mode/af/speed/pupd/otype
  → GPIOx_MODER = mode
  → GPIOx_OSPEEDR = speed
  → GPIOx_PUPDR = pupd
  → GPIOx_OTYPER = otype
  → GPIOx_AFRL/AFRH = af
```
