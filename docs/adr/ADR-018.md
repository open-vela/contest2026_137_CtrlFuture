# ADR-018: XSPI 接口驱动

## 状态

Proposed

## Phase

P2

## 目标

> GitHub Issue: #23
> 验证级别: MEASURED

实现 STM32N6 XSPI（扩展 SPI）接口驱动，
支持连接外部 NOR/NAND Flash、PSRAM 等存储器。

## 上下文

STM32N6 有 2 个 XSPI 实例（XSPI1/2），
支持 1/2/4/8 线 SPI 协议，最高时钟频率 200MHz。
DS14791 Section 32: XSPI。

XSPI 用于连接外部 Flash（ADR-019 启动介质），
也可连接 PSRAM 扩展内存。

## 设计

### 模块架构

```
XSPI 接口
├── 协议模式
│   ├── 1 线 SPI (经典)
│   ├── 2 线 Dual SPI
│   ├── 4 线 Quad SPI
│   └── 8 线 Octo SPI
│
├── 传输模式
│   ├── 命令-地址-数据 (标准)
│   ├── 连续传输 (流模式)
│   └── 内存映射 (XIP)
│
└── DMA 支持
    └── GPDMA 通道 → 高速传输
```

### NuttX 框架对接

```
NuttX MTD 框架:
  mtd_dev_s → 注册 Flash 设备
    → /dev/mtdblockN

文件系统:
  mount("/dev/mtdblock0", "/mnt/flash", "littlefs", ...)
```

### 数据流

```
XSPI 读取 (内存映射模式):
  CPU → XSPI 地址空间 → 自动发送命令
    → Flash 返回数据 → CPU 读取

XSPI 写入 (命令模式):
  应用 → MTD write()
    → XSPI 发送写命令 → Flash 编程
    → 状态轮询完成
```
