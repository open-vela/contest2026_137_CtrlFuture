# ADR-016: RTC 实时时钟

## 状态

Done

## Phase

P1

## 目标

> GitHub Issue: #21
> 验证级别: MEASURED

实现 STM32N6 RTC 驱动，提供实时时钟功能，
支持闹钟、唤醒、日历读取。

## 上下文

STM32N6 的 RTC 模块使用 LSE 32.768kHz 时钟源，
提供日历（年/月/日/时/分/秒）和闹钟功能。
RTC 在 VBAT 供电下可独立运行（ADR-009）。

DS14791 Section 33: RTC。

## 决策

使用 LSI 32kHz 作为 RTC 时钟源（STM32N6570-DK 未焊接 LSE 晶振）。

- **时钟源**: LSI ~32kHz（精度 ±5%，满足文件时间戳需求）
- **用途**: 为 SD 卡 FAT 文件系统提供时间戳（创建/修改时间）
- **初始化位置**: `board_late_initialize()` 中调用 `stm32n6_rtc_initialize()`
- **默认时间**: 上电后从编译时间初始化，可通过 NSH `date` 命令手动设置
- **闹钟/唤醒**: 不使用，EdgeSight 持续运行无需定时唤醒

## 设计

### 模块架构

```
RTC 模块
├── 日历功能
│   ├── 二进制 / BCD 模式
│   ├── 年/月/日/时/分/秒/星期
│   └── 亚秒精度
│
├── 闹钟功能
│   ├── 闹钟 A / 闹钟 B
│   ├── 可按日/时/分/秒匹配
│   └── 产生中断或唤醒事件
│
├── 唤醒定时器
│   ├── 周期性唤醒
│   └── 支持 Stop 模式唤醒
│
└── 时钟源
    ├── LSE 32.768kHz (首选)
    ├── LSI ~32kHz (备用)
    └── HSE 分频 (可选)
```

### NuttX 框架对接

```
NuttX RTC 框架:
  rtc_initialize() → 注册 RTC 设备
    → /dev/rtc0

用户空间:
  open("/dev/rtc0")
  ioctl(RD_RTC_TIME, &tm)     ← 读取时间
  ioctl(WR_RTC_TIME, &tm)     ← 设置时间
  ioctl(RD_RTC_ALARM, &alarm) ← 读取闹钟
  ioctl(WR_RTC_ALARM, &alarm) ← 设置闹钟
```

## 理由

SD 卡录像文件需要有效时间戳便于事后检索和排序。
LSI 精度虽不如 LSE，但对文件时间戳（秒级）完全够用。
board_late_initialize 初始化确保 RCC 时钟树已就绪，RTC 配置可靠。
