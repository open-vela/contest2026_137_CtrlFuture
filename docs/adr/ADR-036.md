## 状态

## Phase

P4

## 目标

> GitHub Issue: #41
> 验证级别: MEASURED

实现 STM32N6 Neural-ART NPU 驱动，
支持神经网络模型的硬件加速推理（600 Gops）。

## 上下文

STM32N647X0 内置 Neural-ART NPU 加速器，特性：
- 600 Gops 算力（INT8）
- 支持 CNN、Transformer、LSTM 等模型
- 硬件卷积、池化、全连接、激活函数
- 2MB 专用 SRAM（NPU SRAM）
- 依赖 HPDMA（ADR-025）进行数据搬运

DS14791 Section 43: NPU (Neural Processing Unit)。
NPU 是 STM32N6 最大卖点，用于边缘 AI 推理。

## 设计

### 模块架构

```
Neural-ART NPU
├── 计算引擎
│   ├── 卷积加速器 (Conv2D)
│   ├── 矩阵乘法 (MatMul)
│   ├── 池化 (Max/Average Pool)
│   ├── 激活函数 (ReLU/Sigmoid/Tanh)
│   └── 量化支持 (INT8/INT16)
│
├── 内存
│   ├── NPU SRAM (2MB, 专用)
│   ├── 权重加载 (Flash → NPU SRAM)
│   └── 激活缓存 (SRAM ↔ NPU SRAM)
│
└── 模型格式
    ├── STM32Cube.AI 导出 (.onnx → .tflite)
    ├── 量化模型 (INT8)
    └── 运行时模型加载
```

### NuttX 框架对接

```
NPU 设备接口:
  register_driver("/dev/npu0", &npu_ops)

应用层:
  fd = open("/dev/npu0", O_RDWR)
  ioctl(fd, NPU_IOC_LOAD_MODEL, &model_info)
  ioctl(fd, NPU_IOC_SET_INPUT, &input_buf)
  ioctl(fd, NPU_IOC_INVOKE, 0)
  ioctl(fd, NPU_IOC_GET_OUTPUT, &output_buf)
  → 推理结果

典型 AI 流程:
  摄像头 → DCMIPP → 预处理
    → NPU 推理 → 后处理
    → 结果显示 (LTDC) / 网络上传 (GMAC)
```

### 数据流

```
推理流程:
  1. 加载模型: Flash → NPU SRAM
  2. 输入数据: SRAM → NPU SRAM (HPDMA)
  3. NPU 计算: 各层依次执行
  4. 输出结果: NPU SRAM → SRAM (HPDMA)
  5. 后处理: CPU 解析推理结果

实时目标检测:
  DCMIPP → 帧缓冲 (320x240)
    → NPU → 检测结果 (bbox + class)
    → CPU 绘制框 → LTDC → LCD
