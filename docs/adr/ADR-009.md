## 状态

Proposed

## Phase

P1

## 目标

> GitHub Issue: #14
> 验证级别: MEASURED

实现 STM32N6 电源管理子系统，支持电压调节器配置、
低功耗模式（Stop/Standby）、电源域控制。

## 上下文

STM32N6 有多个独立电源域（VDD/VDDA/VDDIO2/VBAT），
电压调节器支持多种模式（Range 1 高性能 / Range 2 低功耗）。
DS14791 Section 6: PWR 电源控制器。

PLL 配置和高速外设需要正确的电压调节器范围。
低功耗模式（Stop/Standby）需要 PWR 控制寄存器。

## 设计

### 模块架构

```
PWR 电源控制器
├── 电压调节器控制
│   ├── Range 1 (高性能, 1.2V)   ← 默认
│   └── Range 2 (低功耗, 1.0V)
│
├── 低功耗模式
│   ├── Sleep (Cortex-M WFI)     ← 最浅
│   ├── Stop (保持 SRAM)         ← 中等
│   └── Standby (复位唤醒)       ← 最深
│
├── 电源域控制
│   ├── VDD 域 (数字逻辑)
│   ├── VDDA 域 (模拟外设)
│   └── VBAT 域 (备份域)
│
└── 唤醒源
    ├── WKUP 引脚
    ├── RTC 唤醒
    └── LPTIM 唤醒
```

### NuttX 框架对接

```
NuttX 电源管理框架:
  pm_initialize()              ← 注册电源管理
  pm_activity(domain)          ← 报告活动
  pm_stay(domain, state)       ← 保持状态
  pm_relax(domain, state)      ← 释放状态

低功耗模式:
  up_idle() → WFI              ← Sleep 模式
  pm_suspend() → Stop 模式
```
