# ADR-027: 通用定时器

## 状态

Accepted — 定时/周期中断 (TIM2 /dev/timer0)、单次定时 (TIM5 /dev/oneshot)、
PWM 输出 (TIM3 /dev/pwm1) 与输入捕获 (TIM15 /dev/cap0) 四项功能均已实现
并真机 MEASURED。PWM+捕获通过 TIM3→TIM15 片内互连回环验证（无需外部接线
或示波器）。编码器接口本项目无使用场景，不实现。

## Phase

P4

## 目标

> GitHub Issue: #32
> 验证级别: MEASURED

实现 STM32N6 通用定时器（TIM2-TIM5, TIM12-TIM17）驱动，
支持定时、PWM 输出、输入捕获、编码器接口等通用定时功能。

## 上下文

STM32N647X0 有多个通用定时器：
- TIM2/TIM5: 32-bit 计数器
- TIM3/TIM4: 16-bit 计数器
- TIM12-TIM15: 16-bit（部分通道较少）
- TIM16/TIM17: 16-bit 基本定时器

DS14791 Section 32: General-purpose timers。
通用定时器是嵌入式系统最常用的外设之一。

## 决策

实现通用定时器的四项核心功能并全部真机 MEASURED：

- **定时/周期中断**：TIM2（32-bit，/dev/timer0），1 MHz tick
- **单次定时**：TIM5（32-bit，/dev/oneshot），自由运行 + 输出比较报警
- **PWM 输出**：TIM3 CH1（/dev/pwm1），PWM mode 1
- **输入捕获/频率回读**：TIM15（/dev/cap0）

PWM 与输入捕获的真机验证难点：远端测试台无示波器、无外部接线，
普通 TIM PWM 又无 LPTIM 那样的内部握手标志（ARROK/CMP1OK），
无法仅凭“配置成功”判定波形真实产生。解决方案是 **片内互连回环**：
TIM3 将其更新事件作为 TRGO 输出（tim3_trgo），TIM15 经内部触发
ITR2 选中该触发并工作在外部时钟模式，计数器按 TIM3 每个 PWM 周期
递增一次，从而以纯片内路径读回频率（全程不出芯片，不占用任何 GPIO）。

> **注**：最初计划走 TISEL TI 输入捕获回环（RM0486 表 538 列出
> TIM15 tim_ti1_in2 = TIM3_CH1），但真机实测该 TI 复用抽头不传递
> 内部信号（捕获恒为 0），故改用 OC1REF/UPDATE→ITR2 触发链路。
> 触发链路只有每周期一个脉冲，可测频率但不可测占空比。

编码器接口本项目无使用场景，不实现。

### 真机发现：定时器内核时钟修正

回环频率初测为标称值的约 2 倍。根因：STM32N6 定时器组时钟
timg_ck 在 RCC_CFGR2.TIMPRE=00（复位默认）时等于 sys_bus_ck
（AXI 系统总线时钟，取自 HPRE 分频之前），而非 PCLKx。FSBL 将
HPRE 保持 /2，故 PCLKx = sys_bus_ck/2，但定时器仍以完整
sys_bus_ck（= SYSCLK）运行。board.h 原先用 PCLKx 作为
`STM32_APBx_TIM_FREQUENCY`，导致所有定时器 tick 快 2 倍（TIM2/TIM5
的 cmocka 仅校验相对定时，掩盖了该潜在错误）。已修正为 SYSCLK。

## 设计

### 模块架构

```
通用定时器 (TIM2-TIM5, TIM12-TIM17)
├── TIM2/TIM5 (32-bit)
│   ├── 4 路通道 (OC/IC)
│   ├── 编码器模式
│   └── 级联 64-bit 定时
│
├── TIM3/TIM4 (16-bit)
│   ├── 4 路通道
│   └── PWM/输入捕获
│
├── TIM12-TIM15 (16-bit)
│   ├── 2 路通道
│   └── 通用定时/PWM
│
└── TIM16/TIM17 (16-bit)
    ├── 1 路通道
    └── 基本定时
```

### NuttX 框架对接

```
NuttX 定时器框架:
  timer_initialize()
    → 注册 /dev/timerN

NuttX PWM 框架:
  pwm_register("/dev/pwmN", &tim_dev)

应用层 (PWM):
  fd = open("/dev/pwm0", O_RDONLY)
  ioctl(fd, PWMIOC_SETCHARACTERISTICS, &cfg)
  ioctl(fd, PWMIOC_START, 0)

应用层 (输入捕获):
  fd = open("/dev/capture0", O_RDONLY)
  read(fd, &pulse_width, sizeof(pulse_width))
```

### 数据流

```
PWM 输出:
  应用 → ioctl(PWMIOC_SETCHARACTERISTICS)
    → 配置 PSC/ARR/CCRx
    → TIM 输出比较 → GPIO
    → 外设（LED/舵机/蜂鸣器）

定时中断:
  应用 → ioctl(TCIOC_SETTIMEOUT, &timeout)
    → 配置 ARR
    → 计数溢出 → 中断
    → timer_ops->timeout_handler()

1. [x] 实现通用定时器时基初始化（TIM2, 1 MHz tick）
2. [x] 集成 NuttX timer 框架（/dev/timer0 字符设备下半层）
3. [x] 实现单次定时（TIM5, 自由运行计数器 + 输出比较报警，
   /dev/oneshot，集成 NuttX oneshot 框架）

   集成 NuttX PWM 框架）
5. [x] 实现输入捕获/频率回读（TIM15 外部时钟模式经 ITR2 计 tim3_trgo，
   /dev/cap0，集成 NuttX capture 框架）
6. [x] 修正定时器内核时钟（timg_ck = SYSCLK，非 PCLKx）
7. [x] 编译验证

## 验证标准

- [x] `ci-check.sh` 编译通过（BUILD）
- [x] 定时中断周期正确（drivertest_timer 真机 PASS，MEASURED）
- [x] 单次定时触发/自由运行计时/取消余量正确
  （drivertest_oneshot 真机 PASS，MEASURED）
- [x] PWM 输出 + 输入捕获经片内回环验证：TIM3 驱动 1 kHz PWM，
  TIM15 经 ITR2 回读频率约 1 kHz（`tim_cap` 真机 PASS，MEASURED；
  回环全程片内，不出芯片故不证明信号到达外部引脚；触发链路每周期
  一个脉冲，仅测频率不测占空比）

## 理由

SysTick 满足 EdgeSight 全部定时需求（100Hz tick + work_queue 调度）。
通用定时器在本项目无明确使用场景，实现后闲置浪费开发资源。
