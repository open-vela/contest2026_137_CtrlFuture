# ADR-027: 通用定时器

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #32
> 验证级别: MEASURED

实现 STM32N6 通用定时器（TIM2-TIM5, TIM12-TIM17）驱动，
支持定时、PWM 输出、输入捕获、编码器接口等通用定时功能。

## 上下文

STM32N647X0 有多个通用定时器：
- TIM2/TIM5: 32-bit 计数器
- TIM3/TIM4: 16-bit 计数器
- TIM12-TIM15: 16-bit（部分通道较少）
- TIM16/TIM17: 16-bit 基本定时器

DS14791 Section 32: General-purpose timers。
通用定时器是嵌入式系统最常用的外设之一。

## 设计

### 模块架构

```
通用定时器 (TIM2-TIM5, TIM12-TIM17)
├── TIM2/TIM5 (32-bit)
│   ├── 4 路通道 (OC/IC)
│   ├── 编码器模式
│   └── 级联 64-bit 定时
│
├── TIM3/TIM4 (16-bit)
│   ├── 4 路通道
│   └── PWM/输入捕获
│
├── TIM12-TIM15 (16-bit)
│   ├── 2 路通道
│   └── 通用定时/PWM
│
└── TIM16/TIM17 (16-bit)
    ├── 1 路通道
    └── 基本定时
```

### NuttX 框架对接

```
NuttX 定时器框架:
  timer_initialize()
    → 注册 /dev/timerN

NuttX PWM 框架:
  pwm_register("/dev/pwmN", &tim_dev)

应用层 (PWM):
  fd = open("/dev/pwm0", O_RDONLY)
  ioctl(fd, PWMIOC_SETCHARACTERISTICS, &cfg)
  ioctl(fd, PWMIOC_START, 0)

应用层 (输入捕获):
  fd = open("/dev/capture0", O_RDONLY)
  read(fd, &pulse_width, sizeof(pulse_width))
```

### 数据流

```
PWM 输出:
  应用 → ioctl(PWMIOC_SETCHARACTERISTICS)
    → 配置 PSC/ARR/CCRx
    → TIM 输出比较 → GPIO
    → 外设（LED/舵机/蜂鸣器）

定时中断:
  应用 → ioctl(TCIOC_SETTIMEOUT, &timeout)
    → 配置 ARR
    → 计数溢出 → 中断
    → timer_ops->timeout_handler()
