# ADR-026: 高级定时器（TIM1/TIM8）

## 状态

Accepted（决策：**不实现** TIM1/TIM8 高级定时器驱动，见「决策」节）

## Phase

P4

## 目标

> GitHub Issue: #31
> 验证级别: MEASURED

实现 STM32N6 高级定时器（TIM1/TIM8）驱动，
支持互补 PWM、死区插入、刹车输入等电机控制功能。

## 上下文

STM32N647X0 有高级定时器 TIM1 和 TIM8，特性：
- 16-bit 递增/递减/中心对齐计数器
- 4 路独立通道 + 3 路互补输出
- 可编程死区时间插入
- 刹车（Break）输入保护
- 重复计数器（Repetition Counter）

DS14791 Section 31: Advanced-control timers TIM1/TIM8。
高级定时器专为电机控制和功率变换设计。

## 决策

EdgeSight 不使用高级定时器 TIM1/TIM8，跳过实现。

EdgeSight 无电机控制、互补 PWM、死区插入等需求。
系统定时使用 SysTick（ADR-003 已实现），无需额外硬件定时器。
TIM1/TIM8 驱动不在任何关键路径上。

## 设计

### 模块架构

```
TIM1/TIM8 (高级定时器)
├── 时基
│   ├── PSC 预分频器 (16-bit)
│   ├── ARR 自动重载 (16-bit)
│   └── RCR 重复计数器
│
├── 输出比较 (OC)
│   ├── OC1-OC4: PWM 模式 1/2
│   ├── 互补输出 OC1N-OC3N
│   ├── 死区时间插入 (DTG)
│   └── 刹车输入 (BKIN)
│
├── 输入捕获 (IC)
│   ├── IC1-IC4: 边沿触发
│   └── 编码器模式
│
└── 触发/同步
    ├── TRGO 主模式输出
    └── 从模式 (Reset/Gated/Trigger/External)
```

### NuttX 框架对接

```
NuttX PWM 框架:
  pwm_register("/dev/pwm0", &tim1_pwm_dev)

应用层:
  fd = open("/dev/pwm0", O_RDONLY)
  ioctl(fd, PWMIOC_SETCHARACTERISTICS, &pwm_cfg)
  ioctl(fd, PWMIOC_START, 0)

电机控制典型配置:
  freq = 20kHz
  dead_time = 1μs
  complementary = true
```

### 数据流

```
PWM 输出:
  应用设置 duty cycle
    → pwm_ops->set()
    → 配置 CCRx 寄存器
    → TIM1 CHx + CHxN 互补输出
    → 死区硬件自动插入
    → GPIO → MOSFET 驱动 → 电机

输入捕获:
  外部信号 → GPIO → TIM1 ICx
    → 边沿检测 → CCRx 锁存
    → 中断 → pwm_ops->capture()
    → 返回脉宽/频率

## 验证标准

本 ADR 为不实施决策，无驱动验证项。通用定时/PWM/输入捕获需求已由
ADR-027（通用定时器 TIM2/TIM3/TIM5/TIM15）覆盖并真机 MEASURED；
系统节拍由 SysTick（ADR-003）满足。

## 理由

高级定时器面向电机控制场景，EdgeSight 作为视觉 AI 设备无此需求。
SysTick 已满足系统调度和延时功能，无需引入额外定时器复杂度。
