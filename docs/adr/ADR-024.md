# ADR-024: FDCAN

## 状态

Done

## Phase

P3

## 目标

> GitHub Issue: #29
> 验证级别: MEASURED

实现 STM32N6 FDCAN（灵活数据速率 CAN）驱动，
支持 CAN 2.0 和 CAN FD 协议。

## 上下文

STM32N647X0 有 FDCAN 控制器，支持：
- CAN 2.0A/2.0B 协议
- CAN FD（灵活数据速率，最高 8Mbps）
- ISO 11898-1:2015 标准

DS14791 Section 39: FDCAN。
CAN 总线用于汽车电子、工业控制。

## 决策

EdgeSight 不使用 FDCAN，跳过实现。

EdgeSight 是 AI 视觉哨兵设备，通信走 Ethernet (MQTT)，
不涉及 CAN 总线通信场景（非汽车/工业控制应用）。
FDCAN 驱动不在任何关键路径上，无阻塞关系。

## 设计

### 模块架构

```
FDCAN 控制器
├── CAN 2.0 模式 (1Mbps)
├── CAN FD 模式 (8Mbps)
├── 消息 RAM
│   ├── 标准帧过滤器 (11-bit ID)
│   ├── 扩展帧过滤器 (29-bit ID)
│   ├── TX FIFO/Buffer
│   └── RX FIFO
└── 时间触发 CAN (TTCAN)
```

### NuttX 框架对接

```
NuttX CAN 框架:
  can_register("/dev/can0", &fdcan_dev)

应用层:
  fd = open("/dev/can0", O_RDWR)
  write(fd, &frame, sizeof(frame))
  read(fd, &frame, sizeof(frame))
```

## 理由

EdgeSight 定位为网络连接的 AI 边缘设备，所有上行数据走 TCP/IP 协议栈。
CAN 总线在本项目无应用场景，实现该驱动无收益。
