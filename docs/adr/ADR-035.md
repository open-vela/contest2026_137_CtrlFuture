# ADR-035: H.264 编码器

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #40
> 验证级别: MEASURED

实现 STM32N6 H.264 硬件视频编码器驱动，
支持摄像头视频流的实时硬件编码。

## 上下文

STM32N647X0 有硬件 H.264 编码器（VENC），特性：
- H.264 Baseline/Main/High Profile
- 最高 1080p@30fps 编码
- 硬件运动估计和变换
- CBR/VBR 码率控制
- 依赖 DCMIPP（ADR-033）提供原始帧

DS14791 Section 42: VENC (Video Encoder)。
H.264 编码用于视频录制、实时传输、AI 视频分析。

## 设计

### 模块架构

```
VENC (H.264 编码器)
├── 编码模式
│   ├── I 帧 (关键帧)
│   ├── P 帧 (预测帧)
│   └── GOP 配置 (I/P 比例)
│
├── 输入
│   ├── YUV420 (NV12)
│   ├── YUV422
│   └── 来自 DCMIPP Pipe1
│
├── 输出
│   ├── H.264 NAL 单元
│   ├── 码率控制 (CBR/VBR)
│   └── DMA 输出到 SRAM
│
└── 控制
    ├── 分辨率/帧率设置
    ├── QP 值 (量化参数)
    └── 码率上限
```

### NuttX 框架对接

```
NuttX V4L2 编码器接口:
  video_register("/dev/video_enc0", &venc_dev)

应用层:
  fd = open("/dev/video_enc0", O_RDONLY)
  ioctl(fd, VIDIOC_S_FMT, &h264_fmt)
  ioctl(fd, VIDIOC_REQBUFS, &req)
  ioctl(fd, VIDIOC_STREAMON, 0)
  read(fd, &nal_buf, sizeof(nal_buf))
  → 返回 H.264 NAL 数据

视频流传输:
  DCMIPP → VENC → H.264 NAL
    → RTP 打包 → 网络传输 (ADR-022)
```

### 数据流

```
编码流程:
  DCMIPP Pipe1 → YUV420 帧
    → VENC 运动估计
    → 变换 + 量化
    → 熵编码 (CABAC/CAVLC)
    → NAL 单元 → DMA → SRAM
    → 应用 read()
